## Ownership And Recovery

Originals retain separate dependency state and updates. Bible package updates
must never remove or rewrite a transferred original through an old file manifest.
Legacy same-name handoff requires a complete, unchanged package-owned tree;
unmanaged or modified files are preserved. Failure compensation must match the
exact current dependency backup. Package and dependency transactions are separate;
an interrupted handoff resumes only from verified ownership and current digests.

No hook, helper, setup, credential or external communication is authorized by
skill import. Functional invocation must use the actual host capability.
Repository implementation checks do not imply production installation.
